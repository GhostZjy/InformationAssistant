# 安检工作台

安检班组一体化工作台。把信息上报、时间线提醒、禁限带品速查，与班前会生成、奖惩计分、队员档案、月度汇报、迎检自查整合在一个工具里。纯前端、原生 ES 模块、无需构建，数据只存在本机浏览器。

## 功能

底部 5 个主页签：

- **上报**：模板化生成上报文本。竖向模板列表（可搜索、按分组折叠）、变量自动填充、物品字段联动速查可搜索下拉、实时预览、复制前漏填拦截、复制自动存结构化历史。含「制作模板」（粘贴现成文本反向生成模板）与「管理模板」。
- **时间线**：每日任务到点提醒、今日待办（现在该做/接下来/逾期未完成）、任务联动模板自动切换。
- **速查**：禁带/限带/A·B 类图像特征/处置口径/汇报口径/勤务考勤/奖惩分值/考点速查等分类，搜索命中自动展开，A/B 类卡片可「用这条上报」直接带物品名进简报。
- **班组**（二级页签）：班前会/驻站培训内容积木生成、奖惩计分（自动提示符合奖励条款的查获＋手动录入，按月/按人汇总）、队员档案（入职/培训/擅长岗位/备注＋奖惩累计）、月度汇报草稿、迎检自查清单。
- **我的**（二级页签）：历史记录（复用按结构化取值精准回填）、设置（线路站点/安检点/群名/队员/自定义变量/主题/通知）、数据备份与导入导出。

## 目录结构

```
index.html              入口
.nojekyll               GitHub Pages 跳过 Jekyll
assets/
  css/
    base.css            重置/变量/布局/头部/页签/子页签
    components.css      按钮/表单/弹层/提示/计分/档案/清单等组件
    views.css           各页面专属样式
  js/
    main.js             启动/导航/事件总线
    core.js             DOM/工具/能力检测/事件总线
    ui.js               弹层 Sheet / 提示音 Sound
    data.js             静态数据(奖惩条款/班前会积木/迎检清单/速查分类)
    store.js            统一数据层(读写/规范化/迁移/快照/导入导出)
    report.js           上报引擎(模板/表单/预览/制作模板/复用反解)
    timeline.js         时间线/提醒/今日待办
    lookup.js           速查/速查转上报
    history.js          历史记录/复用
    team.js             班组五模块/计分逻辑
    settings.js         设置/数据管理界面
```

模块依赖单向无环：`core ← ui ← store ← report ← {timeline, lookup, history, settings}`，`team` 依赖 `store/data`，跨视图刷新与导航通过 `core.js` 的事件总线解耦。

## 本地预览

ES 模块需通过 HTTP 访问（不能双击 `file://` 打开）：

```bash
cd 本目录
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署到 GitHub Pages

1. 新建仓库（如 `security-workbench`），把本目录** contents **（`index.html`、`.nojekyll`、`assets/`）推到仓库根目录。
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
3. 约 1 分钟后访问 `https://<你的用户名>.github.io/security-workbench/`。

全部资源使用相对路径，项目站点（带仓库名前缀）可直接运行，无需改配置。`.nojekyll` 已放置，避免 Jekyll 处理。

## 数据迁移

首次打开后，到 **我的 → 设置 → 数据 → 导入配置**，选择旧「信息助手」导出的 `.json`：

- 自动识别并迁移旧版 `infoAssistant.v5` / `infoAssistantV4` / 旧班组工作台配置。
- 模板、历史、速查、队员、设置全部保留；计分/档案/清单等团队字段自动补齐。
- 也可用「合并导入」只并入模板/速查（同名覆盖），不动历史与设置。

## 数据存储与备份

- 所有数据存于浏览器 `localStorage`（键 `securityWorkbench.v1`），不上传任何服务器。
- 每天首次打开自动快照，保留最近 7 份，可在「数据 → 备份与恢复」一键回滚。
- 建议定期「导出配置」做离线备份；换机/清缓存前务必导出。

## 技术说明

- 原生 HTML/CSS/JavaScript（ES Modules），无框架、无构建、无外部依赖。
- 移动优先，自适应桌面；支持深浅色主题。
- 奖惩条款与班前会积木依据《广州市总保安服务有限公司地铁安检项目奖惩实施细则（试行）》2026.10.1 修订及相关业务文件整理；速查内容随配置导入。正式认定与处置以运营单位现行文件和现场民警意见为准。
